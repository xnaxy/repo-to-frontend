# 真实后端到前端：适配与联调

当用户要求真实对接前端时读取；解释/独立图片任务不因此增加后端。这里补充 project-grounding.md 的执行路径，不另建第二份事实源。接口合同继续以实际源码、激活配置和运行证据为依据。

## 解析与简报：先确认可连接边界

在能力合同内记录后端启动方式、依赖服务/worker、前端访问地址/代理、鉴权方式、测试账号或合法会话的可用性、数据样本性质和允许的测试写入范围。探测已有环境与客户端，不默认执行陌生安装/启动脚本；缺少凭据只记录缺口，绝不把服务端密钥写进前端。

逐项核对将展示的字段和动作，分开记录源码支持、schema支持、测试样例、运行观测。OpenAPI存在不证明与当前部署相同；比较关键method/path、挂载前缀、请求响应和状态码，冲突按激活源码/配置查因。未知且影响外观/承诺时BLOCKED_CONTRACT；合同明确但服务暂不可用可进行获准设计/实现，真实联调仍NOT_RUN，不声称可用对接已完成。

无HTTP的CLI/库不能在浏览器直接调用：识别已有浏览器/WASM/桥接方案；没有时列出桥接需求，不虚构已有API。已有授权允许后端集成/新增最小桥接时，可在该范围实现并独立验证，不重复求同意；仅要求前端或浏览器操作不自动扩大为新增服务器进程、部署或暴露本地执行能力。超出明确改动范围时，提出具体最小桥接方案并取得对应授权，受影响真实旅程保持BLOCKED_CONTRACT，其他取证继续。GraphQL/RPC/事件协议优先原生schema及已有客户端，不能为用OpenAPI工具把它们改写成虚假REST。

## 构建：优先消除手写接口漂移

先复用仓库已验证的客户端/共享类型/生成命令；只有出现重复手写路径、字段或类型漂移风险，才按 [github-toolkit.md](github-toolkit.md) 选择工具。TypeScript+已核验OpenAPI可选openapi-typescript/openapi-fetch；已有等价方案不再叠加。小型接口可用明确的适配函数，不为生成两条请求引入平台。

生成前冻结schema及来源版本，生成后按B/U/I映射检查真正使用的操作，记录生成器版本/命令、输入哈希、生成物路径与类型检查结果。类型编译不能证明运行响应满足schema，更不能证明权限和业务语义；实际响应仍按关键字段、单位、可空、状态及领域不变量校验。不得使用any/强制断言把不一致隐藏成通过。

在视图与传输之间保留一个项目级适配边界，集中处理响应包装、金额精度、时间、空值、分页及错误。后端权威计算不在前端另写一套伪等价算法。异步任务按真实状态驱动，区分请求已受理与业务完成；取消浏览器请求不等于取消后端任务。切换对象后旧响应不得覆盖新状态。

## 构建与验收：两条证据链分别记录

1. **合同/模拟测试**：用已核实的响应样本或明确合成数据检查等待、错误、空值、权限、分页、异步和过期响应。现有测试工具足够时不装MSW；需要跨组件复用网络级响应或稳定复现难触发状态时才考虑MSW。模拟不能自动降级用户的真实目标。
2. **真实联调**：使用不含应用mock、测试路由拦截或替代fetch的独立运行配置和干净浏览器上下文；先确认没有启动网络模拟及缓存回放。Network面板出现请求/200不足以排除MSW、客户端中间件或代理伪响应。使用受控样本ID、请求关联或可获得的服务端观测将真实请求、返回与可见UI结果关联；无法确认来源就标未证实。

每个约定关键旅程记录：环境与服务版本可知/未知、账户角色（不含凭据）、输入、实际请求/状态码、响应关键字段、UI显示与持久结果、时间及证据定位。至少覆盖成功与实际相关的失败/权限/空态；稀有失败只在mock中验证时单列，不能说真实环境全状态通过。生产数据写入、删除、付费或广泛探测不由“测试”二字自动授权；优先已授权的可恢复测试数据。

已有OpenAPI/GraphQL及可恢复测试环境，且需要系统检验响应/schema、边界输入或操作链时，可选Schemathesis；限定操作、认证、预算和数据清理，不能默认对生产地址全量fuzz。无适用schema或只有少量关键旅程时直接执行针对性集成测试；工具缺失不阻断可等价完成的检查。

联调与设计、视觉、mock结果分别写入run-state。在realIntegration.status中，服务不可用且未执行为NOT_RUN；已有响应但无法排除模拟/确认来源为UNVERIFIED_SOURCE；观察到实际不一致为FAIL；仅在真实来源及约定旅程有证据时记PASS，并列出覆盖场景与未运行状态。离线可解释/可编辑不代表离线可访问远端后端。schema/部署/鉴权或适配层变化时重新核验受影响客户端、prompt、参考状态和真实旅程。
