# 文字、图标与框架的关系校准

文字超框、编号压框、内容贴底或字重丢失时，在构建前读本节。参考清单分别记录容器、内容组、文本行/样式片段、图标和编号，不能只登记卡片外框。

## 先区分关系，再调整坐标

- 包含：记录每段文字归属哪个内容区及四边留白。图标占据的列不是文字可用宽度；用网格或弹性布局明确图标列、间隙、文字列，文字列允许收缩。检查真实文本Range片段，不仅看元素外框或scrollWidth；裁切/省略号不能算修复。
- 相邻：编号/标签与正文框是独立对象，明确独立槽位或参考允许的跨框锚点。不能把所有相交都判错，也不能因编号原本贴边而忽略它遮住文字。检查预先列出的不应相交对象，允许重叠的对象另记录理由和前后层次。
- 对齐：图标、标题、多行正文组成内容组。比较组的联合范围与父区四边间隙；参考要求居中时居中整个组，不只居中标题。居中与不越界仍可能同时贴满上下边，因此从原图/用户要求分别建立最小四边留白，不以中心偏移检查替代。区分卡片内居中、页面分区内居中和视口居中。原图非对称布局不强制50%；用户指出贴底时优先确保完整内容和相邻留白，记录必要的纠偏例外。
- 字重：逐样式片段记录普通/粗体，指标列、行标题、公式变量不能因父表格font-weight:400而丢失。列标题th和数据标签td分开列检查，tbody全部加粗仍可能漏掉表头。不要整行全加粗代替局部强调。CSS数值700不证明使用了真实粗体字形，字体审计与截图同时验证；缺少真实bold时记录浏览器合成，不能静默禁用合成导致视觉变细。

## 修复顺序与反例

先锁用户字体策略和实际加载，再核父区尺寸、内容可用宽度、图标/编号槽位、字号/行高/字重，最后校准细小位置。一次改变一个原因变量；不要以逐字绝对定位、全局缩放字体或隐藏越界掩盖错误。

每次改共享样式，复验全部消费者：最长标题、最短标题、多行说明、有/无图标、普通/粗体、英文数字混排。保存修前/修后同尺度截图及实现；另验相邻框、最后一行、底边间隙。几何测试只支持已列关系，未登记的文本/伪元素/SVG不得自动算通过。更换字体后重做这些检查，不能沿用旧截图。

## 可复用测量

`scripts/audit-layout-relations.mjs`导出`auditLayoutRelations(page, contract)`，接收现有Playwright page，只读当前状态，不写文件/导航/改样式。例：

```js
const report = await auditLayoutRelations(page, [
  {id:'title-in-card',kind:'containment',container:'#card',selector:'#title',tolerance:1},
  {id:'badge-gap',kind:'separation',a:'#badge',b:'#panel',minGap:4},
  {id:'group-y',kind:'alignment',container:'#card',members:['#icon','#content'],axis:'y',targetOffset:0,tolerance:2,minGaps:{top:8,bottom:8}},
  {id:'metric-bold',kind:'weight',selector:'#metric-label',expected:700},
]);
```

选择器与容差从原图合同和本次用户要求建立，示例不是全局默认。包含测文本Range相对父容器扣除边框/内边距的内容区；隐藏裁切不会消除原始Range越界。间距测显式对象轴对齐边框距离；重叠对象若参考允许，不加入禁止重叠合同。对齐是给定members边框的联合范围相对父内容区中心偏移，不能以一个占满卡片的空wrapper代替真实内容组；其内部文本还应单独测包含。targetOffset可非零，不把非对称参考强制居中。

测量前明确参照边：默认`containerBox:'content'`扣除CSS边框/内边距；从原图可见卡片外边缘量留白时使用`containerBox:'border'`。两种量不可混比，不能在失败后随意换参照边通过测试；应先保留参考量法，再检查工具是否测了同一对象。minGaps分别作用于选定参照边，不重复扣除已经体现在原图间隙中的padding。

每项PASS_RELATION仅指给定关系通过；总状态始终RELATION_OBSERVATIONS_NOT_ACCEPTANCE。MISSING/AMBIGUOUS/HIDDEN/UNSUPPORTED/ERROR不算通过。工具不验证真实墨迹、遮挡层次、所有参考内容、实际粗体文件；原生控件文字、生成内容、变换/zoom等需另测。外部调用保存报告、同态截图与源版本，再作人工逐区对照。
