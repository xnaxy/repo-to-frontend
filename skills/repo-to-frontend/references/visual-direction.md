# 按任务选择视觉结构

新设计须先判断任务与参考边界；采用配方是可选的结构辅助，不是业务事实来源或强制模板。先自问：读者要完成什么？什么布局最直接支持它？反过来检查：套入结构是否丢失事实、状态或原有参考？有足够输入就自主选择，不新增例行确认。

## 选择与证据

新设计可用 [选择器](../scripts/select-visual-recipe.mjs) 筛选 [精选库](visual-recipes.json)。只加载命中的配方，不加载上游整套图库。先写一个profile.json，例如：

```json
{"artifact":"ui","task":"compare","density":"dense","referenceLocked":false}
```

以共享Skill目录为工作目录运行 `node scripts/select-visual-recipe.mjs profile.json`；`--validate`只检查目录格式。支持artifact：ui / diagram / document / brand-board；task：operate / compare / understand / read / persuade / brand；density：sparse / medium / dense。按内容量与阅读任务判断密度，不能按词内含ui/ai等子串猜类别。

| 结构 | 适用任务 |
|---|---|
| task-workspace | 完成输入、操作并读取结果 |
| analytical-workbench | 比较趋势、类别和明细 |
| technical-explainer | 理解机制、方向和分支 |
| editorial-report | 连续阅读论证或报告 |
| brand-landing | 已证实价值的落地页表达 |
| brand-system | 明确要求的品牌规范与应用 |

NO_MATCH是允许的：继续基于事实自行设计，记录没有合适配方，不能偷换任务或把不匹配变成通用默认。多个候选由当前任务选一个并说明理由；用户指定风格优先，配方仅补结构建议。

在03-design-brief.md记录profile、选择状态、recipeId（无匹配则为空）、选择器返回的catalogSha256及一句取舍理由；该摘要按解析后的JSON序列化计算，不是磁盘文件字节哈希。来源条目附本地阅读快照哈希；reviewed只表示阅读过，不表示版权许可、模型验证或上游分类正确。六项均为本项目重新整理，不复制第三方图片和业务文案。

## 从结构到生图提示词

04-image-prompt.md直接包含：①实际内容、字段、单位与来源；②布局关系与阅读顺序；③字体层级、配色角色和素材要求；④画布/视口；⑤当前状态、控件动作及其结果；⑥明确的禁止添加内容。每一项按任务需要组织，不强制六段或固定3–5个页面模块。

对影响业务含义的标题、结果条件、警告和说明，在prompt中列出允许上图的准确文案；只有结果名称而没有解释文案时，不让图片模型自行补写条件。布局提示、行为约束与实际显示文字分开标记。实图逐条比对，尤其检查否定词、异常与成功条件是否反转；不以prompt正确代替成图正确。

配方不能替代能力/交互/图像合同。事实、准确文案和完整状态覆盖优先于布局；不使用占位正文、虚构客户证言、数字、商标或新增按钮凑版式。分析任务继续执行 [设计质量](design-quality.md)，动态值继续执行 [数据适应](data-generalization.md)。技术图在prompt列出主链及异常分支的“起点—条件—终点”，逐条核对图上连线连续可追踪；拒绝/跳过标签不能代替有依据的报告或出口连接。来源未说明终点时标记未知，不自行接到成功节点。中文小字必须实际看图确认，提示词写对不代表图已对。

多页/多态复用同一套字体、颜色角色、间距和导航规则，按内容调整布局，不把每个状态换成另一种风格。保留原有图集清单，不能因为配方适合单张图就缩减状态。

## 固定参考与交接

已有选定参考且未授权重设计时，不重新选型；若调用选择器使用 `{"referenceLocked":true}`，返回REFERENCE_LOCKED且无候选。普通修图保留已选风格。使用支持图像编辑的工具时，把当前图作为编辑引用传入并限定变更区域/内容，不能只重新发送文字就宣称风格已锁定；若只能重生，明确记录为重生，并重新核对整图风格及语义。build/verify只消费最终参考与合同，不能以配方为理由重排界面。

本工具只读目录和profile、输出建议，不修改run-state或开关。选型证据保存在简报/提示词中；不要为了接入它重建run-state。配方或提示词变化若影响实际视觉要求，按 [交接协议](stage-handoff.md) 更新对应产物/合同摘要并使受影响的批准或审查失效；仅目录更新不自动强制旧任务重新设计。图片审核与独立审查的默认值和继承规则均不变。

## 验证边界

目录校验只验证字段、来源标记和可筛选性，不能自动判定作者诚信、内容授权或视觉质量。旧/新同输入实验按 [迁移验证](skill-transfer-validation.md) 执行；旧版已正确行为计为回归。真实图片中的错字、错误曲线和关系必须如实记录，单次样本不证明普遍提升；没有实际前端验证，不宣称复刻质量已改善。
