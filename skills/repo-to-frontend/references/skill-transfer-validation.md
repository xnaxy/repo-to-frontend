# 从案例失败到可迁移的复刻能力

适用于用户要求改进本Skill。案例是发现故障与验证的输入，不是通用能力的替代交付。严格复刻执行仍遵循locked-image-reconstruction.md。

前半段准确性改动优先做仓库到契约/提示词的独立情境验证，不强制付费生图。检查遗漏入口、跨包消费者、权限/开关、异步状态、数据转换、缺失模块与虚构接口；至少包含不同项目结构。给执行者原始证据，不给期望答案；结果区分实际仓库前向运行与合成情境决策。原规则本已正确的行为不得算新增改善；没有同条件对照不声称因果提升。格式校验不证明语义正确，有限情境不证明任意仓库完整。

## 避免把错误的提取方式批量放大

编码前从原图挑选能暴露当前方法风险的区域：例如最密的文字表格、最复杂的连线交叉或最细的图标，而不是只挑最容易的标题卡。先完成该区域的原图清单、真实DOM/SVG、同尺度截图和逐项比对。

OCR结果只是候选转录，不能直接成为“已验证完整”的内容层。OCR漏字时，给已识别对象全部加ID并不能发现漏掉的原图对象。回看放大的原图区域，逐行核对文字、符号、数字和换行；难辨项标UNKNOWN。OCR字框高度不能直接当CSS字号，先用字体、字宽、行高与基线验证。

不要把OCR切出的单字/碎词直接当布局叶节点。先按原图恢复文本行、段落、表格行列和数值归属，再交给浏览器正常排字；仅在样式或语义确实分离时拆成子span。逐字绝对定位会掩盖字体/间距问题，并破坏选取、换行和编辑。保留OCR坐标作取证，不将其当作排版答案。

风险区域的扩展关卡必须检查：逐行文字和数值无遗漏、文本没有越出原图所属容器、换行/截断方式一致、图标与关系方向齐备。用真实文字布局盒检查，不只量卡片外框。越界先核父区宽度、内边距、实际字体、字重、字距和原图换行；不截字、加省略号或无依据缩字来通过。只对“内容存在”测试转绿不足以扩展。未完成关卡的整页草稿不能作为可复用布局样板。

局部像素使用[strict-replica-tools.md](strict-replica-tools.md)的分区诊断，以原图预先定义的区域比较；空白的未实现画布不能污染局部结论。它只是诊断，不能替代内容/边/状态关卡，也不能据局部通过宣布整页通过。

原图→清单→DOM检查遗漏，DOM→清单→原图检查新增；两条方向都要检查。先保存风险区域的清单、真实截图、逐项差异和修复后复验，再展开整页或同类区域。在这之前只可建立承载风险区域的空画布，不用“先做草稿”绕过校准。校准通过指本轮已知失败机制被反例与实际截图验证消除，不等于未知字体已确认或该区域零像素差；剩余未知单列，仍阻断完整1:1。代表区通过只允许扩展实施，不代表其余区域通过。

关系图的清单单位是一条语义边，不是一条任意SVG path。每条边独立ID、from/to、方向与锚点；分段可同属该边，但不要把多条独立关系压进一个带多个M命令的复合路径后只验一个端点/箭头。渲染后逐边核对箭头，合并SVG优化不得改变关系数或可见端点。无箭头的连接同样明确记录，不自动补因果方向。

风险区与整页采集使用不同的阶段/轮次目录，保存所对应实现的指纹；不复用会覆盖前序截图的输出位置。若先行证据已被覆盖，记录缺失，当前整页截图不能补证过去已通过风险关卡。实现改变后旧截图仅作历史，不作为当前验收依据。

## 每次修正必须有可迁移机制

### 在构建中迭代，不在整套完成后补规则

每发现一个实际差异，留下最小可复核记录：原图区域/节点 → 当前截图同区域 → 预期与实际 → 原因假设 → 本轮改变的变量 → 修复后截图与相邻消费者回归 → 是否需要改Skill。先问“这是内容识别错、布局传播错、素材缺失，还是测量口径不同？”再决定改哪层。已有规则未执行时补执行证据或工具约束，不再堆同义指令；仅项目数值/坐标错误留在案例；反复出现的机制才写入Skill。一个差异未定位，不用多做页面抵消它。

密集表格、步骤列表和连续卡片需检查累积偏移：列宽正确仍可能因字体、内边距和换行多出一行，将后续内容推入页脚。逐行比较上下边界、文字可见行数/基线、最后一行到下一分区的间隙，并同时看完整父区；只测首行、总宽或容器不溢出会漏掉错误。以原图为依据记录预期，不将该案例的行数/间距写成通用常量。优先修正最早偏移处的字体/宽度/内边距原因，再检查后续全部行；不要逐行补负margin、遮挡或缩小整页来消除症状。反例同时覆盖短行和会换行的长行，防止只为最长行让其他行退化。

每轮截图与当时可复现实现成对保存：自包含页保存该HTML；多文件页保存改变的文件及可恢复的基线/补丁或提交，记录资源和状态。仅保存最终源码及历史哈希不能恢复早期实现。参考图片无需重复复制，但保存稳定路径与指纹。历史源缺失时记录证据缺口，不补写“已复现”。

### 图形几何与数据计算分开校准

当实际搭建发现标准图表组件与参考的条长、节点距离或面积不符，先判断参考是否真的使用统一数值尺度。逐系列记录原图基线、起终点、正负方向及对应显示值；用多个可辨数据点检验候选尺度，不从一个条形猜整个图。先排除截断坐标轴、对数尺度和不同系列尺度；两个点只能支持候选映射，不能证明整图线性或判定图形错误。数据不足时标UNKNOWN。

若参考图自身比例不一致，严格复刻的参考状态保存其观测几何，计算层仍保留正确数值，并在例外账本说明两者冲突。不要静默用标准图表“修正”图片，也不要为匹配长度篡改数值。只对已提供参考的状态声称视觉一致；编辑后的无参考状态采用明确、可解释的数据映射，另验计算和联动，不把原始像素坐标外推成业务计算。若要求纠正误导图形，另交纠正版，不冒称原图1:1。

通用规则的验证包含两个相反案例：统一尺度参考应保持数值映射；非统一尺度参考应保留观测几何并披露冲突。不能把本次发现泛化成“所有图表都用固定像素”。

编辑态映射记录零点、定义域、尺度与整组更新策略，不将各条临时拼成不同规则。参考态由完整数据、筛选条件和界面状态共同确定；恢复这些条件时恢复参考观测几何，其他状态按明确映射重算。若只有局部参考或恢复条件未知，标明未验证，不仅凭某一个数值相同就切回截图布局。

记录：失败证据 → 原因假设 → 通用改动 → 反例 → 独立复验。区分参考提取、字体/素材缺失、父子布局、图形关系、状态和验收盲区。只修改支持该原因的规则或工具；项目坐标、术语、数据和手工修好的答案留在案例目录，不进入Skill。

连续局部调整不收敛时先检查参考/实际的测量对象与环境是否等价，再查字体及原资产；不要继续堆坐标补丁。未知内容允许有披露的近似草稿，不允许自动美化、换模板、用整图贴底或放宽门槛后称1:1。

## 验证提升，而不只是验证拒绝能力

将三种证据分开：工具能抓错、执行者遵循流程、仅图输入能否还原。工具受控变异不能代替图片前向实验；前向实验也不能证明未知状态的功能。

改动前冻结旧版和输入权限；改动后冻结候选版。相同模型、工具、视口、资产访问、时间/调用预算下分别在新上下文运行。执行者不读原HTML/CSS、其他版本输出或评估者的参考答案；可提供的字体/素材在两组一致，未知条件保留。记录实际权限和所有结果，不挑最佳轮次。缺少旧版同条件运行只能说候选表现，不能声称改进由Skill造成。

隔离也包括测试输出：每个前向执行者在全新空目录生成候选文件，旧交付由评估者保管，验证后才复制到交付位置。失败断言只输出节点ID、期望摘要和差异，不能把整份旧HTML或快照打印给执行者；字符串包含检查可用布尔结果而非整文件diff。若测试、浏览器诊断或共享日志意外暴露旧实现，立即记录受影响运行，不倒写为盲测。改用空目录重跑才能恢复仅图输入的证据等级；原运行仍可作为明确披露的返修实验。

开发样本用于调整；未参与规则修改的留出样本用于检验迁移。选择结构差异而非只换文案/颜色，例如密集排版、关系图、图片主导布局。样本量与重复次数按声称范围和成本预先约定，不能从一个成功样页推断任意项目。留出失败一旦用于修规则，它就转为开发样本，后续用新留出样本检验。

逐样本报告：参考完整性、精确文本/数值、图标与资产、父子区域比例、关系拓扑/锚点、状态、局部及全图像素、功能与耗时。条件/门槛事先确定；平均分不能抵消关键内容丢失、反箭头或错误状态。对未知字体等不可确认项保持BLOCKED/局部未证实，不伪造测量。

## 发布结论

指令决策测试通过只证明该情境下正确决策，不证明网页能1:1。候选规则可供审核；未执行留出复刻时标NOT_RUN，不以新版本号宣布质量提升。正式能力结论必须限定在实测样本、状态和环境，保留未通过案例。安装、包验证、工具回归和能力验证分别记录。
