# 设计提升：语义锁定，视觉可重构

适用：用户允许改变布局并以阅读品质为先。先实际看参考和当前网页，指出变化属于有意改善、语义纠错还是未解决偏差；不追求虚假的像素相同。

## 先决定读者的任务

读者是在查数、理解因果/依赖、比较构成，还是逐步学习？每页一个主要问题和最合适的主图：结构树、时序、瀑布、分布、证据矩阵并不互换。统一外壳与排版，不把不同机制压成同样的卡片。固定内容ID、字段/单位/归属和交互契约，允许位置与信息层级变化。

产品型界面优先一套易读字体、克制层级与熟悉控件；叙述型长文可使用有辨识度的标题排版。留白形成主次，不均匀铺满屏幕；去除无意义边框与重复说明，不删除必要证据。表格局部滚动、图表保留可读标签；移动端重排，不用整页zoom或transform把文字缩小。

## 文字与数值合同

对照图中原文和仓库事实，建表：内容ID / 原文或数字 / 采用内容 / 修改原因 / 页面位置。术语别名首次说明后统一使用；图片虚构财报来源不保留。

建立可复用格式函数，记录结果、输入、金额、比例、整数、图轴各自位数。默认不是固定六位；按用户要求与内容精度决定。结果和台账同精度；若主图简写、详情精确，明确简写规则。使用未舍入数值计算，显示差值的单位区分百分比与百分点。0、缺失、未查询、不可计算不可混用；舍入成0不能宣称数学上恒等成立。

字体族、字重、字号、行高、字距和数码样式分别比较。栅格图片只能估计字形/像素高，不能从文本框高度推断精确字号。查不到原字体时写「未知，采用某字体替代」，等待字体加载并在浏览器验证实际字体；本地字体包留许可证。跨页共享字号角色和tabular-nums数字，不用机械等宽字体替代全部正文。

## 检验品质而非测试数量

先完成一页高密度图、一页长表/矩阵及关键结果态，实际截图检查层级、字形、换行、控件和空缺。然后覆盖全套，不复制相同布局充数。分别检验实际桌面、用户审核窗口与窄屏：整页无横向溢出，表格可滚动，图标签可读，按钮能触达，焦点能返回，公式/年份/来源同源。

每页保留截图与未解决问题。自动测试覆盖格式一致、内容/关系不丢失、真实计算和交互；视觉质量必须实际审图。低质但功能通过时继续修最大三项问题，或明确采用template-fallback.md；不要再通过加更多坐标约束解决审美问题。

## 分析型产品：数据可视化与信息密度准入

当用户需要分析、比较或诊断时，在简报阶段把实际数据形态映射到研究问题和视觉编码：字段、单位、时间/分类、来源与缺失策略。追踪到实际生成/返回链路；只有类型声明、未激活builder或示例不能证明运行时可用。已有序列、构成、关系或状态数据时，不以概括的“有数据再画图”代替映射，也不让大空态成为唯一主参考。数据不足时保留真实限制；允许明确合成的设计主态，但不能当联调证据。

主状态实际审图时记录：读者能否完成主要比较或诊断、图形是否比重复卡片/表格更有效、信息是否被装饰留白挤出、轴/标签/证据是否可读。密度依用户任务与屏幕判断，不强制每页放图或固定图表数量；表单和管理表可以不图形化。趋势缺失不可补0，混合单位分图，非穷尽构成不得自动画整体占比，类别状态不得伪造数值评分。语义/权限未发现错误只证明对应范围，不能据此宣布视觉品质通过。
