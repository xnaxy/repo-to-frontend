# Tabler starter 验证记录

核查日期：2026-09-08。仅覆盖本目录独立 starter，不代表主应用、所有候选模板或图像生成阶段通过。

## 测试先失败，再实现

测试：`tests/starter.test.mjs`。使用既有企业分析项目的 Vitest 3.2.7/jsdom，通过显式绝对路径、`--root`、`--reporter=dot`、`--globals` 运行，没有新增 npm 依赖。

- 实现前：**6 项失败**。原因为官方样式未接入、经典脚本不存在、示例与图位缺失、布局状态缺失、证据视图缺失、本地锚点缺失。并非运行器/模块解析失败。
- 实现后：**6 项通过**。检查本地官方 CSS 的 SHA-256、资源存在、file URL 所需脚本形态、示例和空图声明、两种布局的往返切换、真实证据视图与返回、有效本地锚点。
- 测试只证明这些受测资源与交互，不证明任意适配后的内容正确。

## 真实浏览器

脚本：`scripts/verify-browser.mjs`。Chromium **151.0.7922.34**，DPR=1，浏览器 context 设为 **offline=true**，访问协议为 **file:**。读取与交互均没有开启本地 HTTP 服务。

| 状态 | 视口 | 主要结果 |
|---|---|---|
| 侧栏报告 / 桌面 | 1280×900 | 侧栏 224 px；报告区 x=224；主要图为诚实空位；证据往返和布局切换通过 |
| 顶部导航 / 桌面 | 1280×900 | 导航铺满内容宽度；报告区处于导航下方；交互通过 |
| 侧栏报告 / 手机 | 390×844 | 导航按窄屏横排；整页无水平溢出；表格在自身容器滚动；交互通过 |
| 顶部导航 / 手机 | 390×844 | 窄屏布局完整；整页无水平溢出；交互通过 |

四种状态合计：**0 外部 HTTP(S) 请求，0 控制台 warning/error，0 页面异常**。真实计算样式读到 Tabler 主色 `#066fd1`，确认本地官方 CSS 参与渲染。每种状态都点击 C02、确认本地 evidence details 打开、返回报告，并切换另一种布局。

证据：`verification/browser.json`、四张布局/尺寸 PNG 及 `evidence-desktop.png`。已逐张查看桌面两种布局和手机截图；截图冻结 CSS 动画后保存，避免把瞬间按钮过渡当最终样式。没有做原图相似度比较，也没有生成主要图。

## 检查中的修正与边界

- 初版浏览器探针读取 `CSSStyleSheet.cssRules`，file origin 的 CSSOM 访问限制使探针报 SecurityError，页面本身可正常渲染。改以 stylesheet 路径和真实计算样式验证，不放宽离线要求，也没有为绕过限制启用不安全浏览器参数。
- 原 npm 包的 `/LICENSE` 路径不存在，官方许可从发布标签对应的提交取得；未把不存在的下载写成成功。
- CSS 保留官方全部核心样式，691,465 bytes；未裁剪、未导入外部字体，未包括第三方图表运行库。小型 starter 的体积主要由这个完整 CSS 决定。
- 没有对 Firefox/Safari、完整无障碍标准或性能预算做专项验收；此处的“通过”仅指上述实际检查。
- 示例改成项目真实数据、补主要图、扩展为完整章节后，必须重跑相关测试与浏览器检查；本报告不能沿用作新产物的验收。
